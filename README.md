# 팩트폴리오 (Factfolio)

미디어 리터러시 & 습관 형성 웹 앱. 균형 잡힌 시각을 기르고 매일 꾸준히 읽도록 유도하며, 읽기 기록을 남겨 주는 습관 형성 웹 앱입니다.

## 사용자 스토리

- 나는 성장 중인 학생으로서, 여러 신문 기사를 균형 있게 읽고 싶다. 그래야 중립적인 시선에서 나의 가치관과 성향을 형성할 수 있다.
- 나는 사회에 나가기 전인 학생으로서, 뉴스를 읽는 습관을 들이고 싶다. 그래야 성인이 된 후 사회 흐름을 쉽게 이해하고 접할 수 있다.
- 반대 성향 기사를 강제로 읽으면 거부감이 들기 때문에, 이 앱은 양측이 공통으로 인정하는 데이터(팩트)를 먼저 보여 주어 본질을 파악하게 한다.
- 출석 기반 연속 기록과 시각적 성장 그래픽(유아 → 성인, 씨앗 → 나무)으로 매일 뉴스를 읽고 분석하는 습관을 게임처럼 즐기게 하여 학생들의 뉴스 접근성을 높인다.

## 주요 기능

1. 공통 팩트 브리핑 및 관점(프레임) 비교 레이어
2. 팩트 체크 퀴즈 완료 기반 게이미피케이션 (연속 기록 스트릭 & 성장)
3. 메타인지 읽기 성향 통계 및 맞춤형 관점 보완 추천

## 수용 기준

### 기능 1: 공통 팩트 브리핑 및 프레임 비교 노출

양측 언론사의 주관적 사설·감정적 해석을 배제하고 공통으로 인정하는 객관적 팩트만 담은 리포트를 최상단에 제공하며, 양 진영의 관점 차이를 직관적으로 비교할 수 있어야 한다.

- **Given** 사용자가 메인 화면에서 특정 뉴스 이슈(예: "부동산 정책 발표")를 선택해 상세 페이지에 진입했을 때,
- **When** 상세 화면이 로딩되면,
- **Then**
  1. 보수·진보 기사에서 공통 추출된 `[공통 팩트 브리핑]`이 화면 최상단에 기본 노출된다.
  2. 팩트 브리핑 하단에 양 진영이 강조하는 핵심 키워드·프레임을 보여 주는 `[핵심 프레임 비교 카드]`가 배치된다.
  3. 사용자가 성향 탭(보수/진보)을 클릭하면 해당 진영의 3줄 핵심 해석 요약이 레이어로 출력된다.

### 기능 2: 팩트 체크 퀴즈 및 게이미피케이션 보상 (스트릭 & 정원 성장)

팩트를 제대로 이해했는지 검증하는 퀴즈를 제공하고, 완료 시 듀오링고 스타일의 연속 기록(Streak)과 시각적 정원 성장 보상을 부여한다.

- **Given** 사용자가 `[공통 팩트 브리핑]`을 읽고 하단의 '오늘의 팩트 체크 퀴즈'에 진입했을 때,
- **When** 퀴즈 정답을 맞추고 '이 이슈 완료' 버튼을 누르면 (하루 5개 이슈를 채우면 출석 완료),
- **Then**
  1. 오늘 진행도(N/5)와 경험치(XP)가 오르고, 5개를 채우는 순간 연속 기록(Streak)이 +1일 증가한다.
  2. 메인 화면의 성장 요소가 다음 호칭으로 성장하는 애니메이션이 실행된다.
  3. 당일 출석 달력에 완료 도장(체크 마크)이 표시된다.

성장 호칭(목표 경험치 = 숫자 × 70 XP, 오답 감점이 없을 때의 출석일 수): 아기 0 → 어린이 1 → 초등학생 3 → 중학생 5 → 고등학생 7 → 수험생 10 → 수능 보는 학생 14 → 대학 합격생 18 → 대학생 22 → 취준생 26 → 회사원 30 → 전문가(학자) 45 → 마법사 60. 출석만으로는 성장하지 않고 경험치가 목표에 도달해야 성장하며, 한 번 오른 호칭은 내려가지 않는다.
경험치: 퀴즈 정답 1개당 +10 XP, 하루 5개를 채우면 보너스 +20 XP (하루 70 XP). 퀴즈 오답 1회당 -10 XP(같은 날 같은 이슈의 같은 보기는 1번만 감점). 감점은 0 XP 아래로 쌓여 이후 획득분에서 먼저 차감된다. 하루를 채우지 못하면 그날의 XP는 이어지지 않는다.

### 참고 기사 링크

각 이슈 상세에 '참고한 기사(원문 보기)' 섹션과 성향 탭 하단에 해당 진영 기사 링크를 제공한다.

### 기능 3: 메타인지 기반 읽기 분석 및 맞춤형 관점 보완 추천

편향된 프레임의 뉴스를 편식하고 있는지 통계(도넛/바 차트)로 보여 주고, 부족한 관점의 이슈를 우선 추천한다.

- **Given** 사용자가 최근 1주일간 확인한 이슈 중 특정 성향(예: 진보 프레임 요약)의 소비 비율이 70% 이상일 때,
- **When** 사용자가 '내 균형 리포트' 페이지에 접속하면,
- **Then**
  1. 성향 편중 상태를 나타내는 시각적 그래프와 안내 문구("최근 특정 관점의 해석을 많이 접했어요")가 출력된다.
  2. 메인 추천 섹션 최상단에 반대 관점의 프레임 해석이 담긴 `[관점 보완형 팩트 이슈]` 3건이 우선 노출된다.

## 실행 방법

- 로컬: 폴더의 `index.html`을 더블클릭해 브라우저로 엽니다. (설치·빌드 불필요)
- 배포: GitHub 저장소에 올린 뒤 Settings → Pages → Branch `main` / root 선택.
- 이슈 추가: `data/issues.js`의 `ISSUES` 배열에 같은 형태의 객체를 추가합니다. (`sources`에 참고 기사 `{outlet, side, title, url}` 포함)

## 매일 자동 수집 (GitHub Actions)

- `.github/workflows/daily-news.yml`이 매일 06:00(KST)에 `scripts/fetch_news.py`를 실행해 `data/issues.js`를 갱신·커밋합니다. Actions 탭에서 수동 실행도 가능합니다.
- 보수(조선·동아)·진보(한겨레·경향·프레시안) 언론사 RSS의 제목·링크를 모아, GitHub Models(`GITHUB_TOKEN`, API 키 불필요)로 공통 팩트·프레임 요약·퀴즈를 만듭니다. 기사 본문은 저장하지 않습니다.
- 수집·생성이 실패하거나 유효한 이슈가 5개 미만이면 기존 데이터를 유지합니다.
- 설정: 저장소 Settings → Actions → General → Workflow permissions를 "Read and write"로 두세요. AI 요약은 틀릴 수 있으니 원문 확인을 안내합니다.
- 아직 자동 수집을 돌리기 전에는 예시 이슈와 언론사별 검색 링크가 표시됩니다.
- 기록은 브라우저 localStorage에 저장됩니다 (서버·로그인 없음, 닉네임만 사용).
- 테스트: 주소 뒤에 `?today=2026-11-02`처럼 붙이면 날짜를 바꿔 스트릭을 확인할 수 있고, '내 균형 리포트'의 테스트 도구로 편중 데이터를 넣을 수 있습니다.

## 제약

- 설치·빌드 없이 `index.html`만 열면 동작해야 한다 (순수 HTML/CSS/JS).
- GitHub(GitHub Pages 등)에 웹으로 올려 공개한다.
